# Experiments

This directory is reserved for reproducible experiment definitions and lightweight experiment documentation.

Each experiment definition must reference a version-controlled configuration from `configs/` rather than duplicate configuration values.

Every future experiment must identify:

- configuration
- deterministic random seed
- estimator name and version
- fault scenario
- dataset or simulator provenance
- evaluation metrics
- output directory
- exact execution command

Generated results must not be committed unless explicitly approved.
