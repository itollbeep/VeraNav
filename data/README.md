# Data Directory

Datasets, generated sensor measurements, and derived data products must not be committed to Git.

The planned local-only layout is:

- `data/raw/`
- `data/processed/`
- `data/generated/`

Before any dataset is used, its provenance must be recorded, including:

- source or download location
- dataset name and version
- file checksum
- acquisition or download date
- preprocessing steps
- coordinate frames and units
- applicable license or usage restrictions

No dataset has been added to VeraNav yet.
